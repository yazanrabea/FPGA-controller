# NEMO chip reference workbooks

Lab planning workbooks for the NEMO chips (added 2026-10-13). Both share the same base sheets:
Chips List, Blocks, DFT, Gantt, subblocks/layout for CS-ANN / TD-ANN / NDC, PDK Devices,
Pinout / Pinout_TO1, IO-Pins-Dima, Pinout_Dima, Interface - Dima.

| File | Original name | Difference |
|---|---|---|
| `Blocks.xlsx` | `Blocks.xlsx` | Extra sheet **Blocks Interface - Digital** |
| `IO_pinout.xlsx` | `IO_pinout(2).xlsx` | Base sheets only |

Use the Pinout / IO-Pins sheets when mapping chip pins to FMC LA pins (cross-check with
`docs/reference/pin_mapping_FMC-FPGA.xlsx`). Not verified against the chip package yet.
